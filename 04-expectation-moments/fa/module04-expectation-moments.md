# ماژول 4 — امید ریاضی و گشتاورها

## اهداف یادگیری

پس از تکمیل این ماژول، دانشجویان قادر خواهند بود:

1. مقادیر امید ریاضی را برای متغیرهای تصادفی گسسته و پیوسته محاسبه کنند
2. واریانس و انحراف معیار را محاسبه کرده و معنای مهندسی آن‌ها را تفسیر کنند
3. ویژگی‌های امید ریاضی و واریانس را در تحلیل مهندسی به کار ببرند
4. گشتاورهای مراتب بالاتر را محاسبه و تفسیر کنند
5. از تابع مولد گشتاور (MGF) استفاده کنند
6. گشتاورهای آماری را به کمیت‌های فیزیکی مهندسی مرتبط کنند

## 4.1 مقدمه: چرا آماره‌های خلاصه؟

### نیاز مهندسی

یک توزیع احتمال تمام اطلاعات مربوط به یک متغیر تصادفی را در خود دارد. اما برای تصمیم‌های مهندسی، اغلب به خلاصه‌های موجز نیاز داریم:

- **پردازش سیگنال:** توان میانگین چقدر است؟ → میانگین $X^{2}$
- **کنترل کیفیت:** قطعات چقدر تغییر می‌کنند؟ → واریانس
- **مخابرات:** توان نویز چقدر است؟ $\to E[N^{2}]$
- **قابلیت اطمینان:** عمر میانگین چقدر است؟ → میانگین

گشتاورها (میانگین، واریانس و ...) خلاصه‌های ضروری و **مرتبط با مهندسی** از یک توزیع هستند.

## 4.2 مقدار امید ریاضی (میانگین)

### تعریف — متغیر تصادفی گسسته

$$E[X] = \mu_X = \sum_{x} x \cdot p_X(x)$$

جمع (هر مقدار × احتمال آن).

### تعریف — متغیر تصادفی پیوسته

$$E[X] = \mu_X = \int_{-\infty}^{\infty} x \cdot f_X(x) \, dx$$

### تفسیر مهندسی

مقدار امید ریاضی همان **میانگین درازمدت** است: اگر آزمایش را بارها تکرار کنید و نتایج را میانگین بگیرید، مقدار تقریبی $E[X]$ به دست می‌آید.

| کمیت مهندسی | معنای مقدار امید ریاضی |
|---------------------|----------------------|
| ولتاژ نویز $E[N]$ | بایاس/آفست DC در نویز |
| دامنه سیگنال $E[A]$ | سطح میانگین سیگنال |
| عمر قطعه $E[T]$ | میانگین زمان تا خرابی (MTTF) |
| تأخیر بسته $E[D]$ | تأخیر میانگین |
| خطاهای بیت $E[X]$ | تعداد خطای میانگین |

### مثال: توان میانگین نویز

برای نویز گاوسی با میانگین صفر $N \sim N(0,\, \sigma^{2})$:
- $E[N] = 0$ (بدون مؤلفه DC)
- توان میانگین $= E[N^{2}] = \sigma^{2}$ (این همان واریانس است!)

### مثال: تعداد مورد انتظار ارسال مجدد

پروتکل ARQ: هر انتقال با احتمال $p = 0.8$ موفق است.
تعداد تلاش‌ها $X \sim \mathrm{Geometric}(0.8)$.
$E[X] = \frac{1}{p} = \frac{1}{0.8} = 1.25$ تلاش به‌طور میانگین.

## 4.3 مقدار امید ریاضی یک تابع: $E[g(X)]$

### قضیه LOTUS (قانون آماردان ناخودآگاه)

برای یافتن $E[g(X)]$، نیازی به توزیع $Y = g(X)$ ندارید:

**گسسته:**
$$E[g(X)] = \sum_{x} g(x) \cdot p_X(x)$$

**پیوسته:**
$$E[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f_X(x) \, dx$$

### کاربردهای مهندسی

| تابع $g(X)$ | معنای مهندسی |
|--------------|---------------------|
| $g(X) = X^{2}$ | مقدار میانگین مربع (توان) |
| $g(X) = (X - \mu)^{2}$ | واریانس (توان AC) |
| $g(X)$ = |$X$| | انحراف مطلق میانگین |
| $g(X) = e^{j\omega X}$ | تابع مشخصه |

### مثال: توان میانگین یک سیگنال

سیگنال $X$ دارای PDF $f_{X}(x)$ است. توان $P = X^{2}$.

$E[P] = E[X^{2}] = \int x^{2} f_{X}(x)\,dx$

برای $X \sim N(0,\, \sigma^{2})$: $E[X^{2}] = \sigma^{2}$ (توان نویز برابر واریانس است).

برای $X \sim N(\mu,\, \sigma^{2})$: $E[X^{2}] = \mu^{2} + \sigma^{2}$ (توان کل = توان $\mathrm{DC}$ + توان AC).

## 4.4 واریانس

### تعریف

$$\text{Var}(X) = E[(X - \mu_X)^2] = E[X^2] - (E[X])^2$$

فرمول دوم (فرمول محاسباتی) اغلب آسان‌تر است.

### استخراج فرمول محاسباتی

$\operatorname{Var}(X) = E[(X - \mu)^{2}]$
       $= E[X^{2} - 2\mu X + \mu^{2}]$
       $= E[X^{2}] - 2\mu E[X] + \mu^{2}$
       $= E[X^{2}] - 2\mu^{2} + \mu^{2}$
       $= E[X^{2}] - \mu^{2}$

### تفسیر مهندسی

واریانس **پراکندگی/پخش‌شدگی/عدم‌قطعیت** را می‌سنجد:

| زمینه | معنای واریانس |
|---------|-----------------|
| سیگنال نویز | توان نویز (برای نویز با میانگین صفر) |
| ساخت و تولید | میزان انحراف قطعات از مقدار نامی |
| اندازه‌گیری‌ها | دقت اندازه‌گیری (کوچک‌تر = دقیق‌تر) |
| سیگنال | مؤلفه توان AC |
| عمر | عمر چقدر قابل پیش‌بینی است؟ |

### نکته کلیدی: واریانس = توان در مهندسی

برای یک سیگنال با میانگین صفر $X$:
- $E[X^{2}] = \operatorname{Var}(X) = \sigma^{2}$ = **توان کل**
- برای $X \sim N(0,\, \sigma^{2})$: توان نویز $= \sigma^{2} = \operatorname{Var}(X)$

برای یک سیگنال با آفست DC $(\mu \ne 0)$:
- $E[X^{2}] = \mu^{2} + \sigma^{2}$ = **توان کل = توان $\mathrm{DC}$ + توان AC**
- $\operatorname{Var}(X) = \sigma^{2}$ = **فقط توان AC**

## 4.5 انحراف معیار

### تعریف

$$\sigma_X = \sqrt{\text{Var}(X)}$$

### اهمیت مهندسی

انحراف معیار **همان یکای** $X$ را دارد و بنابراین مستقیماً قابل تفسیر است:

| متغیر تصادفی | یکای انحراف معیار | تفسیر |
|----------------|------------------------|----------------|
| نویز ولتاژ | ولت | ولتاژ نویز مؤثر (RMS) |
| جیتر زمان‌بندی | ثانیه | جیتر مؤثر (RMS) |
| خطای فاصله | متر | خطای موقعیت مؤثر (RMS) |
| دما | °C | نوسان دمای مؤثر (RMS) |

انحراف معیار برای سیگنال‌های با میانگین صفر همان مقدار **مؤثر (RMS)** است.

## 4.6 ویژگی‌های امید ریاضی

### خطی‌بودن (بنیادی)

$$E[aX + b] = aE[X] + b$$

$$E[X + Y] = E[X] + E[Y] \quad \text{(ALWAYS, even if dependent!)}$$

$$E\left[\sum_{i=1}^n a_i X_i\right] = \sum_{i=1}^n a_i E[X_i]$$

### یکنوایی

اگر همواره $X \ge 0$ باشد، آنگاه $E[X] \ge 0$.

اگر همواره $X \ge Y$ باشد، آنگاه $E[X] \ge E[Y]$.

### برای متغیرهای تصادفی مستقل

اگر $X$ و $Y$ مستقل باشند:
$$E[XY] = E[X] \cdot E[Y]$$

> ⚠️ این رابطه برای متغیرهای وابسته برقرار نیست!

### مثال مهندسی: نویز کل

یک سیگنال دریافتی: $R = S + N_{1} + N_{2}$ (سیگنال به‌همراه دو منبع نویز)

$E[R] = E[S] + E[N_{1}] + E[N_{2}] = E[S] + 0 + 0 = E[S]$

(نویز با میانگین صفر، مقدار مورد انتظار سیگنال دریافتی را بایاس نمی‌کند.)

## 4.7 ویژگی‌های واریانس

### مقیاس‌بندی و انتقال

$$\text{Var}(aX + b) = a^2 \text{Var}(X)$$

- افزودن ثابت $b$ واریانس را تغییر نمی‌دهد (انتقال، پراکندگی را تغییر نمی‌دهد)
- مقیاس‌بندی با $a$، واریانس را در $a^{2}$ ضرب می‌کند

### جمع متغیرهای تصادفی مستقل

اگر $X_{1},\, X_{2},\, \ldots,\, X_{n}$ **مستقل** باشند:

$$\text{Var}(X_1 + X_2 + \cdots + X_n) = \text{Var}(X_1) + \text{Var}(X_2) + \cdots + \text{Var}(X_n)$$

> ⚠️ واریانس‌ها فقط برای متغیرهای مستقل جمع می‌شوند!

### مثال مهندسی: جمع توان نویز

دو منبع نویز مستقل ($\sigma_{1}^{2} = 0.01\,\mathrm{V}^{2}$، $\sigma_{2}^{2} = 0.04\,\mathrm{V}^{2}$):

توان نویز کل $= \sigma_{1}^{2} + \sigma_{2}^{2} = 0.05\,\mathrm{V}^{2}$
نویز مؤثر کل $= \sqrt{0.05} = 0.224\,\mathrm{V}$

توجه: مقادیر مؤثر (RMS) مستقیماً جمع نمی‌شوند! $(0.1 + 0.2 \ne 0.224)$

### واریانس میانگین نمونه

برای $n$ مشاهده مستقل و هم‌توزیع $(i.i.d.) X_{1},\, \ldots,\, X_{n}$ با واریانس $\sigma^{2}$:

$$\text{Var}(\bar{X}) = \text{Var}\left(\frac{1}{n}\sum X_i\right) = \frac{\sigma^2}{n}$$

اندازه‌گیری‌های بیشتر → عدم‌قطعیت کمتر در میانگین.

## 4.8 گشتاورهای مراتب بالاتر

### گشتاور مرتبه $n$

$$\mu_n' = E[X^n] = \int_{-\infty}^{\infty} x^n f_X(x) \, dx$$

### گشتاور مرکزی مرتبه $n$

$$\mu_n = E[(X - \mu)^n]$$

- $\mu_{1} = 0$ (همیشه)
- $\mu_{2} = \operatorname{Var}(X)$
- $\mu_{3}$ به **چولگی** مربوط است
- $\mu_{4}$ به **کشیدگی** مربوط است

### چولگی (گشتاور مرکزی سوم، نرمال‌شده)

$$\gamma_1 = \frac{E[(X-\mu)^3]}{\sigma^3}$$

| چولگی | شکل | مثال |
|----------|-------|---------|
| $\gamma_{1} = 0$ | متقارن | گاوسی |
| $\gamma_{1} > 0$ | چوله به راست (دنباله بلند در راست) | نمایی |
| $\gamma_{1} < 0$ | چوله به چپ (دنباله بلند در چپ) | نمایی منفی‌شده |

**اهمیت مهندسی:** چولگی به ما می‌گوید آیا مقادیر حدی در یک جهت محتمل‌تر هستند یا نه. برای قابلیت اطمینان مهم است (توزیع‌های زمان خرابی چوله به راست هستند).

### کشیدگی (گشتاور مرکزی چهارم، نرمال‌شده)

$$\gamma_2 = \frac{E[(X-\mu)^4]}{\sigma^4} - 3$$

(کسر کردن 3 باعث می‌شود کشیدگی گاوسی صفر شود: «کشیدگی مازاد».)

| کشیدگی | تفسیر | معنا |
|----------|---------------|---------|
| $\gamma_{2} = 0$ | مزوکورتیک | دنباله‌هایی شبیه گاوسی |
| $\gamma_{2} > 0$ | لپتوکورتیک | دنباله‌های سنگین‌تر از گاوسی |
| $\gamma_{2} < 0$ | پلاتی‌کورتیک | دنباله‌های سبک‌تر از گاوسی |

**اهمیت مهندسی:** کشیدگی زیاد به معنای مقادیر پرت بیشتر است — برای مدل‌سازی نویز تکانشی مهم است.

## 4.9 تابع مولد گشتاور (MGF)

### تعریف

$$M_X(t) = E[e^{tX}]$$

**گسسته:** $M_{X}(t) = \sum e^{tx} p_{X}(x)$

**پیوسته:** $M_{X}(t) = \int e^{tx} f_{X}(x)\,dx$

### چرا «مولد گشتاور»؟

گشتاور مرتبه $n$ با $n$ بار مشتق‌گیری در $t = 0$ به دست می‌آید:

$$E[X^n] = \frac{d^n M_X(t)}{dt^n}\bigg|_{t=0}$$

- $M_{X}'(0) = E[X]$
- $M_{X}''(0) = E[X^{2}]$
- $\operatorname{Var}(X) = M_{X}''(0) - [M_{X}'(0)]^{2}$

### ویژگی‌ها

1. **یگانگی:** اگر $M_{X}(t) = M_{Y}(t)$ برای تمام $t$ در همسایگی 0 برقرار باشد، آنگاه $X$ و $Y$ توزیع یکسانی دارند.

2. **جمع متغیرهای تصادفی مستقل:** اگر $X$ و $Y$ مستقل باشند:
   $M_{X+Y}(t) = M_{X}(t) \cdot M_{Y}(t)$

3. **تبدیل خطی:** $M_{\text{aX}+b}(t) = e^{bt} \cdot M_{X}(at)$

### MGF توزیع‌های رایج

| توزیع | MGF یعنی $M_{X}(t)$ |
|-------------|------------|
| $\mathrm{Bernoulli}(p)$ | $1 - p + pe^{t}$ |
| $\mathrm{Binomial}(n,\,p)$ | $(1 - p + pe^{t})^{n}$ |
| $\mathrm{Poisson}(\lambda)$ | $\exp (\lambda (e^{t} - 1))$ |
| $\mathrm{Exponential}(\lambda)$ | $\frac{\lambda}{\lambda - t},\, t < \lambda$ |
| $\mathrm{Gaussian}(\mu,\,\sigma^{2})$ | $\exp \left(\mu t + \frac{\sigma^{2}t^{2}}{2}\right)$ |

### کاربرد مهندسی: جمع سیگنال‌های مستقل

اگر مؤلفه‌های سیگنال $X_{1} \sim N(\mu_{1},\, \sigma_{1}^{2})$ و $X_{2} \sim N(\mu_{2},\, \sigma_{2}^{2})$ مستقل باشند:

$M_{X_{1}+X_{2}}(t) = M_{X_{1}}(t) \cdot M_{X_{2}}(t)$
              $= \exp \left(\mu_{1}t + \frac{\sigma_{1}^{2}t^{2}}{2}\right) \cdot \exp \left(\mu_{2}t + \frac{\sigma_{2}^{2}t^{2}}{2}\right)$
              $= \exp \left((\mu_{1}+\mu_{2})t + \frac{(\sigma_{1}^{2}+\sigma_{2}^{2})t^{2}}{2}\right)$

این همان MGF توزیع $N(\mu_{1}+\mu_{2},\, \sigma_{1}^{2}+\sigma_{2}^{2})$ است. بنابراین $X_{1}+X_{2} \sim N(\mu_{1}+\mu_{2},\, \sigma_{1}^{2}+\sigma_{2}^{2})$.

## 4.10 کاربردهای مهندسی گشتاورها

### کاربرد 1: مشخصه‌سازی توان نویز

یک سیگنال نویز $N(t)$ نمونه‌برداری می‌شود. نمونه‌ها میانگین $\mu_{N}$ و واریانس $\sigma_{N}^{2}$ دارند.

- **مؤلفه DC (بایاس):** $\mu_{N}$ — برای نویز ایده‌آل باید صفر باشد
- **توان نویز AC:** $\sigma_{N}^{2}$ — تعیین‌کننده SNR
- **توان کل:** $E[N^{2}] = \mu_{N}^{2} + \sigma_{N}^{2}$

**SNR (نسبت سیگنال به نویز):**
$$\text{SNR} = \frac{E[S^2]}{\sigma_N^2} = \frac{\text{Signal Power}}{\text{Noise Power}}$$

### کاربرد 2: خطای اندازه‌گیری

یک حسگر مقدار واقعی $\theta$ را با خطای $E$ اندازه‌گیری می‌کند:
- اندازه‌گیری: $X = \theta + E$
- $E[X] = \theta + E[E]$ — بایاس در اندازه‌گیری
- $\operatorname{Var}(X) = \operatorname{Var}(E)$ — دقت اندازه‌گیری

**صحّت:** $\lvert E[E]\rvert$ (میانگین چقدر به مقدار واقعی نزدیک است)
**دقت (تکرارپذیری):** $\sigma_{E}$ (اندازه‌گیری‌ها چقدر تکرارپذیر هستند)

### کاربرد 3: آماره‌های عمر قطعه

قطعات عمر $T \sim \mathrm{Exponential}(\lambda)$ دارند:
- میانگین زمان تا خرابی: $\mathrm{MTTF} = E[T] = \frac{1}{\lambda}$
- انحراف معیار: $\sigma_{T} = \frac{1}{\lambda}$ = MTTF
- برای نمایی: ضریب تغییرات CV $= \frac{\sigma}{\mu} = 1$ (همیشه!)

### کاربرد 4: دامنه سیگنال مخابراتی

سیگنال دریافتی $R = A + N$ که در آن $A$ = دامنه سیگنال و $N \sim N(0,\, \sigma^{2})$:
- $E[R] = A$ (دامنه سیگنال به‌طور میانگین حفظ می‌شود)
- $\operatorname{Var}(R) = \sigma^{2}$ (توان نویز واریانس را تعیین می‌کند)
- $\mathrm{SNR} = \frac{A^{2}}{\sigma^{2}}$

## 4.11 مثال‌های MATLAB

### مثال 1: محاسبه گشتاورها از یک توزیع

```matlab
%% Moments of Common Distributions

% Exponential: failure time, lambda = 0.01 (per hour)
lambda = 0.01;
beta = 1/lambda;  % mean = 100 hours

fprintf('=== Exponential Distribution (λ = %.3f) ===\n', lambda);
fprintf('Mean (MTTF) = %.1f hours\n', beta);
fprintf('Variance = %.1f hours²\n', beta^2);
fprintf('Std Dev = %.1f hours\n', beta);
fprintf('Coefficient of Variation = %.2f\n', beta/beta);

% Gaussian: noise voltage, sigma = 0.1V
mu = 0; sigma = 0.1;
fprintf('\n=== Gaussian Distribution (μ=%.1f, σ=%.2f V) ===\n', mu, sigma);
fprintf('Mean = %.2f V\n', mu);
fprintf('Variance (noise power) = %.4f V²\n', sigma^2);
fprintf('RMS noise = %.3f V\n', sigma);
fprintf('E[X²] (total power) = %.4f V²\n', mu^2 + sigma^2);
```

### مثال 2: بررسی ویژگی‌های واریانس

```matlab
%% Variance of Sum of Independent RVs
N = 100000;

% Two independent noise sources
sigma1 = 0.1;   % RMS of noise 1
sigma2 = 0.2;   % RMS of noise 2

X1 = sigma1 * randn(1, N);
X2 = sigma2 * randn(1, N);
Y = X1 + X2;   % Combined noise

fprintf('Var(X1) = %.4f (theory: %.4f)\n', var(X1), sigma1^2);
fprintf('Var(X2) = %.4f (theory: %.4f)\n', var(X2), sigma2^2);
fprintf('Var(X1+X2) = %.4f (theory: %.4f)\n', var(Y), sigma1^2 + sigma2^2);
fprintf('Std(X1+X2) = %.4f (theory: %.4f)\n', std(Y), sqrt(sigma1^2+sigma2^2));
fprintf('\nNote: std devs do NOT add: %.3f + %.3f = %.3f ≠ %.3f\n', ...
    sigma1, sigma2, sigma1+sigma2, sqrt(sigma1^2+sigma2^2));
```

### مثال 3: میانگین و واریانس یک متغیر تصادفی تبدیل‌شده

```matlab
%% E[g(X)] using LOTUS: Power from Voltage
% X = voltage ~ N(0, 0.5V)
% P = X^2 / R, with R = 50 ohms

sigma = 0.5;    % noise voltage RMS
R = 50;         % resistance
N = 100000;

X = sigma * randn(1, N);
P = X.^2 / R;   % instantaneous power

% Using LOTUS: E[X^2/R] = E[X^2]/R = sigma^2/R
E_P_theory = sigma^2 / R;
E_P_sim = mean(P);

fprintf('Mean power: Theory = %.6f W, Sim = %.6f W\n', E_P_theory, E_P_sim);
fprintf('Mean power = %.3f mW\n', E_P_theory * 1000);
```

### مثال 4: گشتاورهای مراتب بالاتر و چولگی

```matlab
%% Skewness and Kurtosis Comparison
N = 100000;

% Gaussian (symmetric)
X_gauss = randn(1, N);

% Exponential (right-skewed)
X_exp = exprnd(1, 1, N);

% Uniform (symmetric, light tails)
X_unif = rand(1, N);

fprintf('Distribution    | Skewness | Kurtosis\n');
fprintf('----------------+----------+---------\n');
fprintf('Gaussian        | %+.3f   | %+.3f\n', skewness(X_gauss), kurtosis(X_gauss)-3);
fprintf('Exponential     | %+.3f   | %+.3f\n', skewness(X_exp), kurtosis(X_exp)-3);
fprintf('Uniform         | %+.3f   | %+.3f\n', skewness(X_unif), kurtosis(X_unif)-3);
fprintf('\nTheoretical:\n');
fprintf('Gaussian:    skew=0, kurt=0\n');
fprintf('Exponential: skew=2, kurt=6\n');
fprintf('Uniform:     skew=0, kurt=-1.2\n');
```

### مثال 5: بررسی MGF

```matlab
%% Verify MGF: Compute moments by differentiation (numerical)
% For X ~ Exponential(lambda)
lambda_rate = 2;
beta_scale = 1/lambda_rate;

% MGF: M(t) = lambda/(lambda - t)
% M'(0) = E[X], M''(0) = E[X^2]

t = 0;
dt = 1e-6;

% Numerical derivatives
M = @(t) lambda_rate ./ (lambda_rate - t);
M_prime = (M(t+dt) - M(t-dt)) / (2*dt);
M_double_prime = (M(t+dt) - 2*M(t) + M(t-dt)) / dt^2;

fprintf('From MGF derivatives:\n');
fprintf('  E[X] = M''(0) = %.4f (theory: %.4f)\n', M_prime, 1/lambda_rate);
fprintf('  E[X²] = M''''(0) = %.4f (theory: %.4f)\n', M_double_prime, 2/lambda_rate^2);
fprintf('  Var(X) = E[X²] - (E[X])² = %.4f (theory: %.4f)\n', ...
    M_double_prime - M_prime^2, 1/lambda_rate^2);
```

## 4.12 مسائل تمرینی

### مسئله 1: محاسبه پایه
یک متغیر تصادفی گسسته $X$ دارای PMF زیر است: $P(X = -1) = 0.2$، $P(X = 0) = 0.5$، $P(X = 1) = 0.2$، $P(X = 2) = 0.1$.

(a) $E[X]$ را بیابید.
(b) $E[X^{2}]$ را بیابید.
(c) $\operatorname{Var}(X)$ را بیابید.
(d) $E[3X + 2]$ را بیابید.
(e) $\operatorname{Var}(3X + 2)$ را بیابید.

**حل:**
(a) $E[X] = (-1)(0.2) + (0)(0.5) + (1)(0.2) + (2)(0.1) = -0.2 + 0 + 0.2 + 0.2 = 0.2$

(b) $E[X^{2}] = (1)(0.2) + (0)(0.5) + (1)(0.2) + (4)(0.1) = 0.2 + 0 + 0.2 + 0.4 = 0.8$

(c) $\operatorname{Var}(X) = E[X^{2}] - (E[X])^{2} = 0.8 - 0.04 = 0.76$

(d) $E[3X + 2] = 3E[X] + 2 = 3(0.2) + 2 = 2.6$

(e) $\operatorname{Var}(3X + 2) = 9 \cdot \operatorname{Var}(X) = 9(0.76) = 6.84$

### مسئله 2: سیگنال و نویز
یک سیگنال دریافتی $R = 2.5 + N$ که در آن $N \sim N(0,\, 0.04)$.

(a) $E[R]$ و $\operatorname{Var}(R)$ را بیابید.
(b) SNR را بر حسب dB بیابید.
(c) $P(R < 0)$ را بیابید — احتمال این‌که سیگنال منفی شود.

**حل:**
(a) $E[R] = 2.5$، $\operatorname{Var}(R) = \operatorname{Var}(N) = 0.04$، $\sigma_{R} = 0.2$

(b) توان سیگنال $= 2.5^{2} = 6.25$، توان نویز = 0.04
    $\mathrm{SNR} = \frac{6.25}{0.04} = 156.25 \to \mathrm{SNR}_{dB} = 10 \cdot \log_{10}(156.25) = 21.94$ dB

(c) $P(R < 0) = P(N < -2.5) = \Phi \left(-\frac{2.5}{0.2}\right) = \Phi (-12.5) \approx 0$ (بسیار نامحتمل)

### مسئله 3: میانگین‌گیری از اندازه‌گیری‌ها
یک حسگر $n$ اندازه‌گیری مستقل از یک ولتاژ ثابت $V = 3.3\,\mathrm{V}$ انجام می‌دهد.
هر اندازه‌گیری: $X_{i} = 3.3 + N_{i}$ که در آن $N_{i} \sim N(0,\, 0.01)$.

(a) برای $n = 1$ مقدار $E[\bar{X}]$ و $\operatorname{Var}(\bar{X})$ چقدر است؟
(b) چه تعداد اندازه‌گیری $n$ لازم است تا $\sigma_{\bar{X}} < 0.01\,\mathrm{V}$ شود؟
(c) با $n = 100$، مقدار $P(\lvert \bar{X} - 3.3\rvert > 0.02)$ چقدر است؟

**حل:**
(a) $E[\bar{X}] = 3.3$، $\operatorname{Var}(\bar{X}) = \frac{0.01}{1} = 0.01$، $\sigma = 0.1\,\mathrm{V}$

(b) $\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} < 0.01 \to \sqrt{n} > 10 \to n > 100$ → به $n \ge 101$ نیاز است

(c) $\sigma_{\bar{X}} = \frac{0.1}{\sqrt{100}} = 0.01\,\mathrm{V}$
    $P(\lvert \bar{X} - 3.3\rvert > 0.02) = P(\lvert Z\rvert > 2) = 2(1-\Phi (2)) = 0.0455$

### مسئله 4: عمر قطعه
قطعات عمر $T \sim \mathrm{Exp}(\lambda = 0.002\ \text{در هر ساعت})$ دارند.

(a) MTTF، $\sigma_{T}$ و ضریب تغییرات را بیابید.
(b) $P(T > 1000\ \text{ساعت})$ را بیابید.
(c) $E[T^{2}]$ را بیابید و تفسیر کنید.

**حل:**
(a) $\mathrm{MTTF} = \frac{1}{\lambda} = 500$ ساعت، $\sigma_{T} = 500$ ساعت، CV $= \frac{\sigma}{\mu} = 1$

(b) $P(T > 1000) = e^{-0.002 \times 1000} = e^{-2} = 0.1353$

(c) $E[T^{2}] = \operatorname{Var}(T) + (E[T])^{2} = 500^{2} + 500^{2} = 500000\,\mathrm{hours}^{2}$
    $\sqrt{E[T^{2}]} = 707$ ساعت (عمر مؤثر)

### مسئله 5: کاربرد MGF
$X$ دارای MGF زیر است: $M_{X}(t) = \frac{1}{3}e^{t} + \frac{2}{3}e^{2t}$.

(a) $X$ چه نوع متغیر تصادفی است؟ PMF آن را بیابید.
(b) با استفاده از MGF مقدار $E[X]$ را بیابید.
(c) با استفاده از MGF مقدار $\operatorname{Var}(X)$ را بیابید.

**حل:**
(a) $X$ گسسته است. با مقایسه با $\sum p_{X}(x)e^{tx}$:
    $P(X = 1) = \frac{1}{3}$، $P(X = 2) = \frac{2}{3}$

(b) $M'(t) = \frac{1}{3}e^{t} + \frac{4}{3}e^{2t}$
    $E[X] = M'(0) = \frac{1}{3} + \frac{4}{3} = \frac{5}{3}$

(c) $M''(t) = \frac{1}{3}e^{t} + \frac{8}{3}e^{2t}$
    $E[X^{2}] = M''(0) = \frac{1}{3} + \frac{8}{3} = 3$
    $\operatorname{Var}(X) = 3 - \frac{5}{3}^{2} = 3 - \frac{25}{9} = \frac{2}{9}$

## 4.13 نکات کلیدی

1. **$E[X]$ = میانگین درازمدت** — مرکز توزیع، مؤلفه DC
2. **$\operatorname{Var}(X)$ = پراکندگی/توان** — برای سیگنال‌های با میانگین صفر، واریانس همان توان است
3. **$\sigma$ همان یکای $X$ را دارد** — مستقیماً به‌عنوان مقدار مؤثر (RMS) قابل تفسیر است
4. **خطی‌بودن امید ریاضی** همواره برقرار است؛ جمع واریانس‌ها نیازمند استقلال است
5. **MGF به‌طور یکتا** یک توزیع را مشخص می‌کند و تمام گشتاورها را تولید می‌کند
6. **در مهندسی:** میانگین → سطح سیگنال، واریانس → توان نویز، انحراف معیار → نویز مؤثر
